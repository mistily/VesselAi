# Vessel AI agents

This folder contains the agent definitions and workflow guidance for Vessel AI, a Slack-integrated project-management assistant.

## Initial focus

Support the insurance-offer PDF processing project by helping teams coordinate work in Slack, capture daily plans and progress, and automate agreed workflow tasks. The agent approach should be extensible to other insurance software projects.

## Planned integrations

- Slack for team conversations and channel-based workflows
- Google Drive for project documents and retrieval-augmented generation (RAG)
- Google Calendar for meetings and reminders
- Google AI Studio / Gemini for AI capabilities
- Whisper for call transcription and executive summaries

Keep future agent instructions scoped, transparent, and designed to work with explicit team approval for actions that change project data or communicate externally.
